<h1>Image Digital Forensics</h1>
<h2>What it does:</h2>
<ol>
<li> File information (name, size, timestamps)</li>
<li>Cryptographic hashes (MD5, SHA-1, SHA-256) for evidence integrity</li>
<li>File signature (magic number) vs extension check</li>
<li>Hidden / appended data check (data after JPEG end marker)</li>
<li>EXIF metadata extraction (camera, date, software, GPS)</li>
<li>Error Level Analysis (ELA) to highlight possible tampering</li>
<li>Writes a text report + ELA image</li>
